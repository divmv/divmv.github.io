# Divya Vemuri — Portfolio

A responsive, static portfolio for GitHub Pages. The site is plain HTML, CSS, and JavaScript; no build step is needed.

## Publish at `https://divmv.github.io`

1. Create a public GitHub repository named **`divmv.github.io`** under the `divmv` account.
2. From this folder, connect that repository as `origin`, then commit and push the site to the `main` branch.
3. In the new repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.
4. The workflow in `.github/workflows/pages.yml` deploys on every push to `main`. The first deployment appears in the repository's **Actions** tab; the site will be at `https://divmv.github.io`.

The site uses information from Divya's resume and links to public GitHub and LinkedIn profiles. It deliberately does not publish the resume PDF, phone number, or email address.
