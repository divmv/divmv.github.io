Selected projects

01 / HARDWARE + SOFTWARE / FPGA · 2025–26

PrimeKart: a prime-number computer

I led the architecture and integration for a Nexys A7 system that tests numbers for primality. The design uses a hardware Sieve of Eratosthenes, 1-bit BRAM, dual FIFO IP, and DDR2 through Xilinx MIG. A keypad sets the test; VGA shows the result.

VerilogVivadoBRAM / DDR2Multi-clock design
